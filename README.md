# Poklaude

Local MVP for a poker preflop drill trainer.

## Run locally

```bash
npm install
npm run dev
```

Open the local Next.js app and test the drill flow.

## V1 scope

- Choose training filters: scenario, stack depth, hero position, villain position.
- Generate preflop action drills from a seeded 20bb chart dataset.
- Track attempts, accuracy, and weak spots in local browser storage.
- Use a mobile-first UI inspired by poker drill apps.

Later we can add range image upload, editable 13x13 grid, Supabase persistence, and AI chart parsing.
