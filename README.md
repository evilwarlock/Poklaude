# Poklaude

Local MVP for a poker preflop drill trainer.

## Live demo

```text
https://evilwarlock.github.io/Poklaude/
```

## Run locally

```bash
npm install
npm run dev
```

Open the local Next.js app and test the drill flow.

## Current V0 scope

- Static GitHub Pages visualization.
- 20bb RFI only.
- Raise/Fold drills from a seeded dataset.
- Greyed-out unavailable options for future scenarios and stack depths.
- Track attempts, accuracy, and weak spots in local browser storage.
- Mobile-first UI inspired by poker drill apps.
